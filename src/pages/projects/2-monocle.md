A native macOS menu-bar app that helps blind and low-vision users magnify on-screen content, recognize text, and hear it read aloud.

- **Live magnification:** A circular magnifier follows the pointer using **ScreenCaptureKit**.
- **On-device accessibility:** **Apple Vision** handles OCR and **AVFoundation** provides spoken reading, keeping everyday use private and local.
- **Keyboard-first controls:** Global shortcuts make OCR capture and reading available without interrupting the current workflow.
- **Optional AI descriptions:** Users can explicitly request a screen description using their own OpenAI API key, stored securely in Keychain.
