### Projects

### Anomalize — Weather Anomaly Detection

A Tauri desktop app for detecting weather anomalies from historical and live data using XGBoost and Random Forest models. Features 5-day risk forecasts, interactive visualizations, Open-Meteo integration, and a Rust-based ONNX inference engine. [GitHub](https://github.com/TonyRoyze/weather-anomaly-detection.git)

### EduCost — Education Cost Predictor

An ML-powered web app that predicts tuition, living, rent, and visa costs for international education using CatBoost and multivariate regression. Includes customizable marketing cards, CSV uploads, and a Next.js frontend with a Python inference backend. [GitHub](https://github.com/TonyRoyze/education-cost-prediction.git)

### Surge Pricing & Profit Dashboard

A machine learning application for dynamic ride-sharing fare prediction and profitability tracking based on demand, driver availability, and weather. Built with React, FastAPI, scikit-learn, and SHAP-based feature selection. [GitHub](https://github.com/TonyRoyze/surge-pricing-dashboard.git)

### Flight Analytics Dashboard

A Next.js dashboard for exploring 300,000+ flight records across Local, Business, and Tourist traveller modes. Features interactive charts, airport maps, tourist attractions, fast indexed filtering, and real-time currency conversion. Built with Recharts and Leaflet. [GitHub](https://github.com/TonyRoyze/flight-dash.git)
